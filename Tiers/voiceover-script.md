# LazyTradie Tutorial: Job Tiers. Voiceover Script (30 s)

Use the **same narrator voice and settings as the main explainer**, so the series sounds like one
product. Generate **one file per line**, exactly as written, and save each to
`Tiers/assets/vo/` with the filename shown. Pauses and timing are handled in the edit.

**Pronunciation:** `LazyTradie` = LAY-zee TRAY-dee (not used in this script, but keep the voice the same).

## Voice 1: Narrator (every line except TV_05)
Same deep, warm, calm male voice as the explainer. Natural pace, not rushed.

## Voice 2: Caller in an emergency (TV_05 only)
A **different voice** from the narrator: a homeowner on the phone, worried and a bit breathless,
but clear. Aussie accent. I add the phone-line sound and room tone in the mix, so generate it clean.
