# LazyTradie AI Receptionist Reel: Every Line

**12 files to make**, one per line, exactly as written. Save each to `receptionist-reel/assets/vo/`
with the file name shown (MP3 or WAV). Pauses and timing are handled in the edit, so don't add
pauses, music or effects.

## Voice: the series narrator (ElevenLabs)
The same narrator voice and settings as the explainer and the Copilot film, so the series sounds
like one product: Stability 50–60 %, Similarity 75 %, Style 0–15 %, Speed 1.0, Speaker boost on.

The reference uses a calm, unhurried narrator who sounds like she's smiling a little: product
launch, not radio ad. Match that delivery. Natural pace, about 140 words per minute.

**LazyTradie** = LAY-zee TRAY-dee. If the TTS gets it wrong, type `Lazy Tray-dee` in the TTS box
only and keep the file name the same.

**Takes:** generate 2–3 takes of R_01, R_10 and R_12, the lines that carry the reel.
