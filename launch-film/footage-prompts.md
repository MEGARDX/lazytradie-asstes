# LazyTradie Launch Film: Footage Prompts (Gemini / Veo)

**For every clip:**
- Use 16:9, the longest length available (8 s), and download at the highest resolution offered
  (1080p if available). Leave a moment of silence before and after each line so I have room to cut.
- Make 2–4 takes of each and keep the best. Name the file after its clip ID (`LF_05.mp4`) and don't
  trim or re-encode it, since I sync the voice against the original audio.
- Every prompt already ends with "no music, no subtitles", because Veo sometimes adds both.

**Presenter consistency:** make the `IMG_P` still first, then start `LF_01` and `LF_02` from that
image (photo-to-video, or as the first frame / ingredient in Flow) so it's the same person in both.

---
